우리학급 포털 편집용 파일

구성
- index.html: 화면과 기능이 들어 있는 웹페이지
- ai-images/: 홈과 로그인 화면에서 사용하는 캐릭터 이미지

사용 방법
1. ZIP 파일을 풀어 주세요.
2. index.html과 ai-images 폴더를 같은 위치에 둡니다.
3. index.html을 웹호스팅 서비스에 올리면 페이지를 확인할 수 있습니다.
4. 화면 문구와 디자인은 index.html에서 수정하고, 이미지는 ai-images 폴더에서 교체할 수 있습니다.

시연 접속 코드
- 관리자: 1357
- 교사: 2468
- 학급 코드: SAEBOM32
- 예시 학생: 학번 1, 김하늘

참고
- 학교 정보, 임원 지정, 게시물은 현재 브라우저에 저장되는 시연 방식입니다. 다른 기기와 공유하거나 실제 학생 계정을 안전하게 운영하려면 서버와 데이터베이스 연결이 필요합니다.
- API 주소를 연동하려면 공개 JSON 응답과 브라우저 연결(CORS) 허용이 필요합니다.
- 페이지에는 미리보기 편집기 연동 스크립트가 포함되어 있습니다. 일반 웹호스팅에서는 없어도 페이지의 주요 기능은 사용할 수 있습니다.
